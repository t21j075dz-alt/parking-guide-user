# 駐車場空き区画案内 ユーザー用アプリ

卒業研究の**利用者向けWebアプリ**です。管理画面とは別リポジトリで公開し、施設選択から駐車区画案内までを4画面で操作します。

## 画面構成

1. 施設選択
2. 条件選択
3. 推奨駐車区画
4. 詳細案内

管理用の編集機能はこのリポジトリには含めません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 4画面、施設絞り込み、位置情報表示、安全確認ダイアログ |
| `styles.css` | スマートフォン表示、ライト／ダーク、駐車場マップ |
| `app.js` | 施設選択、レイアウト取得、区画検索、画面遷移 |
| `facilities.js` | 研究対象120店舗 |
| `location-safety.js` | 継続測位、移動判定、運転中操作の確認 |
| `parking-layouts.js` | クラウド未使用時のレイアウトフォールバック |
| `sync-config.js` | 管理アプリと共通のSupabase公開設定 |

## 管理アプリとの連携

すべての施設は固定の `facilityId` を持ちます。

```text
管理アプリ
  ↓ facilityId
Supabase parking_layouts
  ↓ facilityId
ユーザーアプリ
```

Supabase同期が有効な場合、ユーザーアプリは検索時に最新レイアウトを取得します。通信できない場合はリポジトリ内の `parking-layouts.js` をフォールバックとして使用します。

## 推奨区画の考え方

管理レイアウトに `parkingSpace` が登録されている場合、その区画データを利用します。

建物出入口は、

- `objectType === "buildingEntrance"`
- `guideTarget === true`
- `publicAccess !== false`

を満たすものを案内基準として使用します。

現時点の「入口に近い」はキャンバス上の距離比較です。歩道・車道ネットワークに沿った経路距離ではありません。

## 駐車場マップに表示できるもの

- 駐車区画
- 車道・一方通行
- 歩道
- 横断歩道
- 建物
- 建物出入口
- 駐車場入口・出口・出入口
- 停止線
- 速度抑制ハンプ
- 進入禁止
- カート置き場
- 駐輪場
- 二輪車置場
- 荷捌きスペース
- EV充電器

利用者マップは、案内区画と店舗入口を拡大した模式図を表示します。航空写真は管理画面の位置合わせ用です。

施設所在地は2026-09-28に120店舗すべて再監査しています。固定緯度経度がない店舗でも、管理画面が確認済み住所から決定した `layout.background` の座標を、ユーザー側の距離計算に利用できます。

## 位置情報と安全確認

位置情報は現在地から施設までの参考直線距離と、操作時の移動判定に使用します。

- `watchPosition()` で表示中のみ継続取得
- 測位はメモリー内で使用
- 位置情報そのものは保存しない
- 移動検知中に操作すると「運転中ですか？」を表示
- GPSだけでは運転者と同乗者を区別できないため利用者確認を併用

位置情報を利用する場合はHTTPSまたはlocalhostで開いてください。

## 自動反映設定

管理アプリと同じ `sync-config.js` を設定します。

```js
window.PARKING_REMOTE_CONFIG = Object.freeze({
  enabled: true,
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  publishableKey: "公開用キー"
});
```

利用者側には公開用キーだけを置きます。秘密鍵・service role keyは置きません。

## コメント方針

第三者がコードを追いやすいよう、

- ファイル冒頭に責務・データフロー
- JavaScript関数に日本語の目的コメント
- HTMLに画面単位の構造コメント
- CSSに意味単位のセクションコメント
- 安全処理は「何をするか」だけでなく「なぜ止めるか」をコメント

という形式で統一します。

JSON形式にはコメント構文がないため、JSON内の項目説明はREADMEまたは対応するJavaScriptファイルに記載します。

## 現時点の研究上の注意

- 実店舗のリアルタイム空き情報は取得していません。
- 管理レイアウト未登録施設は研究用シミュレーションを表示します。
- 一方通行などは表示できますが、経路探索への反映は今後の拡張です。
- 試作システムのため、実際の駐車案内用途には使用しません。


## 保存レイアウトの表示

管理画面の論理座標・回転・形状を維持し、利用者画面では案内先に合わせて表示範囲を切り替えます。`background` の座標は施設位置の補助情報として保持します。

### 店舗状態

施設マスターには所在地確認日と営業状態も保持します。

- `active`：現在の店舗情報を確認済み
- `opening-scheduled`：開店予定
- `experiment`：大学の研究用施設

開店予定の施設を掲載する場合は「開店予定」と表示します。旧対象のトライアル山口小郡店は、後述のとおり置換済みです。


## 研究対象店舗の位置監査

2026-09-28の監査後、研究対象120店舗すべてに固定緯度・経度を登録しています。

確認が難しかった旧対象2店舗は、同じ県内の位置確認済み営業中店舗へ置き換えました。

- `target_041`：ホームプラザナフコ 小郡店（山口県）
- `target_117`：ホームプラザナフコ 谷山店（鹿児島県）

置換店舗では `facilityRevision` とレイアウトの店舗識別キーを照合し、旧店舗の航空写真・配置図が残っていても新店舗へ誤表示しないようにしています。

## 無料の多言語音声案内

利用者画面の音声案内は、外部AI APIではなくブラウザー標準の **Web Speech API（SpeechSynthesis）** を使用します。

- APIキー不要・従量課金なし
- 日本語表示時は **Google 日本語** を固定で優先
- 日本語の読み上げ速度は **1倍（標準速度）**
- English表示時は以下の音声案内言語を選択可能
  - English (US)
  - English (UK)
  - 中文
  - 한국어
  - Español
- 選択肢上には音声エンジン名を表示しない
- 内部では各言語のGoogle音声を優先する
- 中国語は zh-CN、韓国語は ko-KR、スペイン語は es-ES
- 選択した言語に合わせて試聴・自動案内開始・駐車区画案内の文章も切り替える
- 言語を選択すると、その言語の短い試聴を自動再生
- Chromeの音声一覧が遅れて読み込まれる場合を考慮し、最大15秒待って対応音声を取得
- 選択言語の音声が端末に存在しない場合は画面上で明示
- 外部AIへ案内文やマイク音声を送信しない


## 案内画面の表示範囲

- 初期表示は案内区画と案内対象の店舗入口を中心に拡大します。
- 「全体を見る」と「案内先を拡大」で表示範囲を切り替えられます。
- 画面の縦横で同じ縮尺を使い、保存座標・回転・形状は維持します。
- 区画番号は案内先だけに大きく表示します。管理用の名称とグリッドは表示しません。
- 公開入口は位置を表示し、案内対象の入口には「店舗入口」のラベルを付けます。
- 登録入口がない場合は区画を中心に拡大し、入口を仮に作りません。
- 地図の表示範囲を切り替えても案内区画は変更しません。

## 修正後の動作確認

Node.js 22以降で、リポジトリのフォルダから実行します。外部ライブラリは不要です。

```sh
node --test tests/regression.test.cjs
```

通信の順序逆転、施設変更・戻る操作による検索取消、音声待機の取消、希望車種の選択を検証します。ネットワークと音声はテスト用の代替処理を使い、本番データを書き換えません。
